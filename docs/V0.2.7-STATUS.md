# PhoenixMail V0.2.8 — Accounts & Local AI

This iteration moves PhoenixMail from a visual prototype toward a usable local mail client.

## Accounts
- Multiple local mail accounts can be created, edited, selected and removed.
- Each account has IMAP and SMTP settings.
- Passwords are kept in memory for the current session; they are not written to `data.json`.
- Default sending account can be selected.
- SMTP and IMAP connection tests are available.

## Local AI
- PhoenixMail can download the recommended Qwen3-0.6B Q4_0 GGUF model into its local `models/` directory.
- The model download is verified against its published SHA-256 before activation.
- llama.cpp `llama-server` can be detected and started locally when installed.
- AI actions remain local and use the OpenAI-compatible llama.cpp chat endpoint.

## Important
- The official PhoenixMail branding is sourced from the standalone `Branding(1)` kit supplied by the project owner.
- UI polishing is intentionally deferred while account, send and AI plumbing are implemented.
