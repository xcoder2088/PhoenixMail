# PhoenixMail Brand Kit

PhoenixMail — open-source, privacy-first email client with adaptive local AI.

## Brand direction
- Primary visual: fiery phoenix + envelope
- Style: powerful, modern, open-source, trustworthy
- Primary palette: flame orange / red / gold with optional violet-blue accents
- Suggested tagline: **Your Mail. Your AI. Your Control.**
- Project license target: **AGPL-3.0**

## Included
- `icons/` — application icons, transparent PNG sizes, ICO, light/dark variants
- `logos/` — horizontal logo and wordmark
- `monochrome/` — white/black/outline variants
- `web/` — SVG wrappers, WebP, favicon and web assets
- `docs/` — this guide

## Important note
The SVG files in this first kit are self-contained SVG wrappers containing the transparent PNG artwork. They are suitable for web/app packaging, but are **not yet true vector artwork**. A later branding pass can trace the mark into native SVG paths once the visual design is frozen.

## Recommended use
- App icon: `icons/phoenixmail-icon-1024.png`
- Windows/macOS/Linux: `icons/phoenixmail-icon.ico` and PNG sizes
- Website header: `logos/phoenixmail-logo-horizontal.png`
- Small UI: 16/32/48/64 px icon variants
- Dark background: primary transparent icon or white monochrome
- Light background: black monochrome or transparent primary icon

## Color starting points
- Flame orange: `#FF7A00`
- Flame red: `#E83218`
- Gold: `#FFC928`
- Deep violet: `#7A2CFF`
- Deep navy: `#080C16`

These are starting brand colors; the exact palette should be finalized after the final vector logo is approved.
