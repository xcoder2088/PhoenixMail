# Contributing to PhoenixMail

PhoenixMail is intended to be a community-driven AGPL project.

## Development principles

1. Privacy first.
2. Local-first by default.
3. No telemetry without explicit opt-in.
4. No provider lock-in.
5. CPU-only support must remain a first-class target.
6. Keep the AI layer provider/model agnostic.

Please open an issue before large architectural changes.
